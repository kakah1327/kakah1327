Conceitos fundamentais

Imagem como matriz de pixels

Uma imagem digital é uma matriz (uma "grade") de pixels. Cada pixel tem uma posição (x, y) e um valor de cor. Em uma imagem RGB, cada pixel guarda três valores — vermelho, verde e azul —, cada um variando de 0 a 255. Em uma imagem em escala de cinza, cada pixel tem um único valor de intensidade (0 = preto, 255 = branco).

"Percorrer" a imagem em Python

É basicamente um laço duplo: um for pra percorrer as linhas (altura) e outro, dentro dele, pra percorrer as colunas (largura). Pra cada posição (x, y), você lê o valor do pixel, calcula um novo valor e grava de volta — geralmente numa imagem nova, pra não estragar a original enquanto ainda está lendo dela. 

for y in range(altura):
    for x in range(largura):
        pixel = pixels[x, y]

Operações pontuais x operações de vizinhança

Pontuais: o novo valor do pixel depende só do valor original dele (negativo, brilho, limiarização). De vizinhança: o novo valor depende também dos pixels ao redor — é o caso da convolução, usada em desfoque, nitidez e detecção de bordas.

Profundidade de bits

É a quantidade de bits usada pra representar cada valor de cor. 8 bits por canal = 256 níveis possíveis (0–255), o padrão mais comum. Quanto mais bits, mais tons diferentes a imagem consegue representar.

Guia de estudos

Lista organizada dos tópicos mais prováveis numa disciplina introdutória de Processamento de Imagens e Visão Computacional. Use como checklist de revisão — de novo, é uma base geral, não o conteúdo oficial do professor.

Processamento de imagens

  • Representação de imagem: matriz de pixels, RGB, escala de cinza
  • Diferença entre operação pontual e operação de vizinhança
  • Negativo, ajuste de brilho e contraste
  • Conversão para escala de cinza (média x luminosidade)
  • Histograma: o que representa e pra que serve
  • Limiarização / binarização de imagens
  • Convolução: como funciona um kernel, o que é o divisor
  • Filtros de suavização (blur) e nitidez (sharpen)

Introdução à visão computacional

  • Detecção de bordas: Laplaciano x Sobel, o que é gradiente
  • Morfologia matemática: erosão e dilatação em imagens binárias
  • Segmentação básica de imagem (separar objeto do fundo)
  • Ideia geral de extração de características (o que torna um objeto identificável)
  • Diferença entre processamento de imagem e visão computacional

Prática em Python

  • Abrir e salvar imagens (ex: biblioteca Pillow/PIL)
  • Acessar e alterar pixels individuais (load(), putpixel)
  • Percorrer a imagem com laços duplos (linhas × colunas)
  • Criar uma imagem nova em vez de alterar a original durante o laço
  • Implementar convolução "na mão" com laços aninhados
