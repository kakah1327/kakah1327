## 🚀 Projetos em destaque

### 📊 VaR Lab — Value at Risk

**Plataforma web para modelagem e backtesting de Value at Risk (VaR) em ativos da B3.**

Projeto desenvolvido como Trabalho de Conclusão de Curso, envolvendo coleta e tratamento de dados financeiros, modelagem de risco e avaliação estatística dos modelos.

O projeto inclui uma aplicação web completa, pipeline de dados financeiros e diferentes metodologias para análise e validação de risco.

**Tecnologias:**

`Python` `Flask` `React` `PostgreSQL` `Análise Quantitativa` `B3`

**Colaboradores:** Cintia, Guilherme e Lucas  
**Orientador:** Prof. Dr. Gilberto Perez
